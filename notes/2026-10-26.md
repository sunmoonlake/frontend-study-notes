### 振り返り　インクリメント演算子（++）

 - 演算子の名前の覚え方
    - インクリメント increment＝増加	++ で1増やす
    - デクリメント	 decrement＝減少	-- で1減らす
    - オペランド operand＝操作される対象	 x++ の x
    - 演算子（オペレーター）operator＝操作する人 + や ++ そのもの
    - 前置 / 後置 prefix / postfix ++x / x++

 - インクリメント演算子（++）は、オペランドの数値を+1する演算子です。
オペランドの前後どちらかにインクリメント演算子を置くことで、オペランドに対して値を+1した値を返します。

```javascript

let num = 1;
num++;
console.log(num); // => 2
// 次のようにした場合と結果は同じ
// num = num + 1;
```
 - インクリメント演算子（++）は、オペランドの前後どちらに置くかによって評価の順番が異なります。
後置インクリメント演算子（num++）は、次のような順で処理が行われます。

 - numの評価結果を返す
 - numに対して+1する

そのため、num++が返す値は+1する前の値となります。

```javascript
let x = 1;
console.log(x++); // => 1
console.log(x);   // => 2
```

- ●つまずきポイント：
x++ は「今の値を相手に渡してから、自分を+1する」という動きをします。つまり console.log(x++) の行では、
1. x の今の値 1 を console.log に渡す
2. そのあとで x を 2 にする
という順番なので、画面に表示されるのは渡された 1 です。x 自体はちゃんと 2 になっているので、次の行の console.log(x) では 2 が出ます。

- たとえるなら、整理券を配る係の人が「今の番号札（1番）をお客さんに渡してから、手元の番号を2番に進める」ようなイメージ

```javascript
let a = 1;
console.log(a++); // => 1（渡してから+1）
console.log(a);   // => 2

let b = 1;
console.log(++b); // => 2（+1してから渡す）
console.log(b);   // => 2
```
- ◾実務では：
この紛らわしさを避けるために `x++` を `console.log()` の中などに埋め込まず、`x++;` や `x += 1;` と単独の行で書くのが一般的

```javascript
// わかりにくい書き方（埋め込み）
let count = 0;
console.log(count++); // => 0 ……え、1じゃないの？と迷う

// わかりやすい書き方（単独の行）
let count2 = 0;
count2++;             // まず増やす
console.log(count2);  // => 1 迷わない
```
- ◾わかりにくいポイント（数学教育とプログラミングの違い）
 - 数学における「代入」と「＝」
   - 「＝」の意味
     - 左右の値や式が「等しい（等式）」を表す
   - 値を入れる（代入）は =（イコール1つ）
   - 値の変化
     - 一度決まった文字（変数）の値は、その文脈では変わらない

 - プログラミングにおける「代入」と「＝」
   - 「＝」の意味: 右側の値を左側の変数（箱）に「入れる（命令）」を表す
   - x = x + 1 という式は成立しない（解がない）:「今の x に1を足して、もう一度 x にしまい直す」という意味になる
   - 「等しいか比較する」は ==（イコール2つ）や === を使う
   - 代入するたびに中身が上書きされて変化する
   - プログラミングでは：
     - 右辺（x + 1）をまず計算する
     - その結果を、左辺の変数 x に代入（上書き）する


## ループと反復処理
同じ処理を繰り返すために同じコードを繰り返し使わず、ループやイテレータなどを使い、反復処理として同じ処理を繰り返し実行する

## for文
：古いコードや解説記事に頻繁に出てくるので、読み書きできるようにしておきます。
- for文は繰り返す範囲を指定した反復処理を書くことができます。

```javascript
for (初期化式; 条件式; 増分式) {
    実行する文;
}
 ```
 for文の実行フローは次のようになります。

1. 初期化式 で変数の宣言
2. 条件式 の評価結果がtrueなら次のステップへ、falseなら終了
3. 実行する文 を実行
4. 増分式 で変数を更新
5. ステップ2へ戻る

```javascript
let total = 0; // totalの初期値は0
// for文の実行フロー
// iを0で初期化
// iが10未満（条件式を満たす）ならfor文の処理を実行
// iに1を足し、再び条件式の判定へ
for (let i = 0; i < 10; i++) {
//   ①スタート   ②続ける条件  ③1周ごとの変化
    total += i + 1; // 1から10の値をtotalに加算している
}
console.log(total); // => 55
 ```
- 解説
 - ① i を0から始めて、② i が10未満の間は繰り返し、③ 1周終わるごとに i を1増やす、という意味です。つまり i は 0, 1, 2, …, 9 と変わり、合計10周します。
 -  i が10になった時点で条件 i < 10 が false になり、ループを抜けます。そこで console.log(total) が実行されて55が表示されます。
 - for文は i = 0 で書くのが定番

## while文
while文は条件式がtrueであるならば、反復処理を行います。

```javascript
while (条件式) {
    実行する文;
}
 ```
つまり
```javascript
let x = 0;
console.log(`ループ開始前のxの値: ${x}`);
while (x < 10) {
    console.log(x);
    x += 1;
}
console.log(`ループ終了後のxの値: ${x}`);
 ```

### 無限ループ

```javascript
let i = 1;
// 条件式が常にtrueになるため、無限ループする
while (i > 0) {
    console.log(`${i}回目のループ`);
    i += 1;
}
```
- ◾️解説：「i が増え続けるので、i > 0 が永遠に true のまま」
