## 条件分岐

 - if文
 条件式の評価結果がtrueであるならば、実行する文が実行されます。

 ```javascript
 if (true) {
    console.log("この行は実行されます");
}
```

実行する文が1つのみの場合は、`{` と `}` のブロックを省略できる

 - if文
 次の値は真偽値へと変換するとfalseとなるため、これらはfalsyな値と呼ばれます

  - 真偽値以外の値
  - ●`false`
  - ●`undefined`
  - ●`null`
  - ●`0`
  - ●`0n`
  - ●`NaN`
  - ●`""`（空文字列）

 - falsyではない値は、trueへと変換されます。（truthy）

```javascript
if (true) {
    console.log("この行は実行されます");
}
if ("文字列") {
    console.log("この行は実行されます");
}
if (42) {
    console.log("この行は実行されます");
}
if (["配列"]) {
    console.log("この行は実行されます");
}
if ({ name: "オブジェクト" }) {
    console.log("この行は実行されます");
}
```

 - true扱い（truthy）とは
  - if文の( )の中には true/false 以外の値を入れてもよく、そのときJavaScriptが「これはtrue扱い？false扱い？」を自動で判断してくれる
 - つまり「false扱いになる値」が決まっていて、それ以外は全部true扱いになる。

 - ●ポイント　実務では、これを「値が入っているかどうか」のチェックによく使う。

```javascript
const userName = "";

if (userName) {
  console.log(userName + "さん、こんにちは");
} else {
  console.log("名前が入力されていません");
}
```

- userName が空なら else 側、何か入っていれば if 側が動きます。（フォームの入力チェック）

- 注意点として、"0" や "false" のように中身が文字列だとtrue扱いになる。見た目にだまされやすい。

 - else if文

  - version が "ES5" ならば "ECMAScript 5" と出力
  - version が "ES6" ならば "ECMAScript 2015" と出力
  - version が "ES7" ならば "ECMAScript 2016" と出力

```javascript
const version = "ES6";
if (version === "ES5") {
  console.log("ECMAScript 5");
} else if (version === "ES6") {
  console.log("ECMAScript 2015");
} else if (version === "ES7") {
  console.log("ECMAScript 2016");
}
```

 - else文
  - if文とelse if文では、条件に一致した場合の処理をブロック内に書いていました。 一方で条件に一致しなかった場合の処理は、else文を使うことで書けます。

```javascript
const num = 1;
if (num > 10) {
    console.log(`numは10より大きいです: ${num}`);
} else {
    console.log(`numは10以下です: ${num}`);
}
```

 - `${num}`とは
 - `num` という変数の中身を、文字列の中に埋め込む
   - 数の中身を「取り出して」文字列の中に差し込むことです。プログラミングでは「埋め込み」や「展開」と呼びます。
   - ${name} が「ここに名前を差し込む」
 - つまり代入の逆

   - 代入の例　
   `const num = 5; // numに5を「入れる」＝代入`


```javascript

const num = 5;
console.log(`りんごが${num}個あります`);
// → りんごが5個あります

const name = "花子";
console.log(`こんにちは、${name}さん`);
// → こんにちは、花子さん
```


 - ネストしたif文
ネストしたif文の例として、今年がうるう年かを判定してみましょう。
うるう年の条件は次のとおりです。

- 西暦で示した年が4で割り切れる年はうるう年です
- ただし、西暦で示した年が100で割り切れる年はうるう年ではありません
- ただし、西暦で示した年が400で割り切れる年はうるう年です

西暦での現在の年は new Date().getFullYear(); で取得できます。 このうるう年の条件をif文で表現すると次のように書けます。


```javascript
const year = new Date().getFullYear();
if (year % 4 === 0) { // 4で割り切れる
    if (year % 100 === 0) { // 100で割り切れる
        if (year % 400 === 0) { // 400で割り切れる
            console.log(`${year}年はうるう年です`);
        } else {
            console.log(`${year}年はうるう年ではありません`);
        }
    } else {
        console.log(`${year}年はうるう年です`);
    }
} else {
    console.log(`${year}年はうるう年ではありません`);
}
```

 - `new Date().getFullYear();`は、今日の日付から「今年が何年か」を取り出すという意味です。今日実行すれば 2026 が返ってきます。

 - new Date() は、「今この瞬間の日時」を表すデータを作ります。年・月・日・時・分・秒がまとめて入ったセットのようなものです。

 - `.getFullYear()` は、そのセットの中から「年」だけを4桁の数字で取り出します。


 ## 振り返り const
 - const は、再代入できない変数を宣言するキーワード。名前は「constant（定数）」の略。
 `const name = "Hanako";`
   - 実務では「基本は const、値を後から変える必要があるときだけ let」

   - `console log` はスニペット登録(clg)
   - `console log with label` もスニペット登録(clv)

 ## 振り返り 関数宣言
  - functionからはじまる文は関数宣言と呼び、次のように関数を定義できます。

```javascript
//関数宣言
function 関数名(仮引数1, 仮引数2) {
    // 関数が呼び出されたときの処理
    // ...
    return 関数の返り値;
}
// 関数呼び出し
const 関数の結果 = 関数名(引数1, 引数2);
console.log(関数の結果); // => 関数の返り値
```

例

```javascript

function double(num) {
    return num * 2;
}
// `double`関数の返り値は、`num`に`10`を入れて`return`文で返した値
console.log(double(10)); // => 20
```

- 関数が何も値を返す必要がない場合は、return文そのものを省略できます。return文を省略した場合は、undefinedという値を返します。

```javascript
function fn() {
}
console.log(fn()); // => undefined
```

- ◾振り返り 文と式
  - JavaScriptは文（Statement）と式（Expression）から構成される
  - 文は式になれない
  - 式は文になれる（式文）
  - 文の末尾にはセミコロンをつける
  - ブロックで終わる文は例外的にセミコロンをつけなくてよい

## 条件分岐 switch文
  - switch文は、次のような構文で式の評価結果が指定した値である場合に行う処理を並べて書きます。

```javascript
const version = "ES6";
switch (version) {
    case "ES5":
        console.log("ECMAScript 5");
        break;
    case "ES6":
        console.log("ECMAScript 2015");
        break;
    case "ES7":
        console.log("ECMAScript 2016");
        break;
    default:
        console.log("しらないバージョンです");
        break;
}
// "ECMAScript 2015" と出力される
```


これはif文で次のように書いた場合と同じ結果になります。


```javascript
const version = "ES6";
if (version === "ES5") {
    console.log("ECMAScript 5");
} else if (version === "ES6") {
    console.log("ECMAScript 2015");
} else if (version === "ES7") {
    console.log("ECMAScript 2016");
} else {
    console.log("しらないバージョンです");
}
```

 - エラー文の種類

`Identifier '...' has already been declared` はconstが二重に宣言できないのに重ねて書いたのでエラーになった。

 - break文
   - `break;`を使って抜けないとcase節が条件に関係なく実行される。

## まとめ

   - if文、else if文、else文で条件分岐した処理を扱える
   - 条件式に指定した値は真偽値へと変換してから判定される
   - 真偽値に変換するとfalseとなる値をfalsyと呼ぶ
   - switch文とcase節、default節を組み合わせて条件分岐した処理を扱える
   - case節でbreak文を省略した場合は、後ろに続くcase節が実行される
